# ADR-0001. Runner внутри lab-control

1 ноября 2026 года. Статус: предложен.

## Контекст

Control готовит эксперимент, управляет прогонами и собирает отчёт. Runner выполняет сценарии HTTP-запросов.
В MVP одновременно выполняется один эксперимент. Масштабировать runner отдельно от Control пока не требуется.

## Решение

Runner остаётся пакетом `lab.control.runner` внутри Control. План и результаты передаются через Java-интерфейсы.
Для исполнения используется отдельный executor, чтобы длительный прогон не занимал потоки обработки HTTP-запросов Control.

Отдельный сервис потребовал бы сетевого протокола, аутентификации и обработки сбоев связи.
Для одного эксперимента это лишняя сложность.

## Последствия

Один процесс упрощает запуск и передачу результатов, но runner и Control делят память и JVM.
Критический сбой runner, например нехватка памяти, может остановить Control.

Решение нужно пересмотреть, если понадобятся независимое масштабирование или изоляция отказов runner.
