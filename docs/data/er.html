Модель данных API Security Lab

ER-представления для разработчиков, doc-wide 1280×640. Показаны выбранные связи, без полного списка столбцов. Все таблицы и FK находятся в shop.dbml и lab.dbml; составные FK и ограничения — в SQL. Сплошные линии здесь обозначают физические FK. Отсутствующий FK между базами не подразумевается. В shop 8 таблиц, в lab 12 (5 control + 2 audit + 5 detection). control.scenario_jobs хранит план встроенного runner; поле deadline_at заменяет распределённый lease. В protected дополнительные UNIQUE ограничивают заказ одним на intent и версию корзины; в vulnerable эти ограничения отсутствуют. Полные ограничения — в shop-protected.sql.
