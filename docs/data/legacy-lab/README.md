# Историческая модель хранения

Эти SQL/DBML/Mermaid-файлы сохранены как архив предыдущего дизайна. Они описывают отменённую схему общего audit, SQL jobs и detector view и не соответствуют действующим межсервисным контрактам.

Не применять их при запуске текущего стенда и не переносить в актуальные миграции. Новая архитектура передаёт access-логи прямо в Detector через HTTP/JSON; Detector хранит их сам, Control получает итоговые incidents.

Актуальные источники: [контракты](../../../contracts/README.md), [логирование и обнаружение](../../04-events-and-detection.md). Внутренние таблицы Control/Detector будут определены при реализации без изменения этих HTTP-интерфейсов.
