Управление и данные

Оператор использует Control API trials. Runner и Fixture - модули Control; Fixture готовит shop DB напрямую. Control управляет Runtime API Shop/Gateway и Detector API. Служебный Bearer отделён от operator Bearer и JWT магазина.

Shop/Gateway отправляют access-логи непосредственно Detector. Detector хранит их сам, не читает план, shop DB или эталон и возвращает только итоговые incidents. Control оценивает их по requestIds и формирует report.

Завершение

Runner completion → Gateway CLOSED → Shop CLOSED → Detector finish с lastSequence → COMPLETED и observedRequestIds → incidents → readonly oracle и report. Пропуски, restart и deadline дают INCONCLUSIVE. При cleanupSafe=false сброс запрещён.

Согласовано с контрактами 25 октября 2026 года. Схемы описывают целевую реализацию.
